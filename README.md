# Campus Register

A simple Web Technology Lab project made with HTML, CSS, and JavaScript.

**Live website:** https://aneesh-gupta-mn.github.io/registration-forms/

## Features

- Registers students with browser validation
- Saves data in `localStorage`
- Prevents duplicate email registrations
- Displays all saved records in a table
- Searches by name, email, phone, or course
- Deletes records after confirmation
- Responsive layout for desktop and mobile

## Run locally

Open `dist/index.html` in a browser. No installation or server is required.

## Storage note

Registrations are saved only in the current browser and device. Clearing browser storage removes the records.
